# WTC Mobile - Glass Finder

Single page to find which tempered glass box fits a phone model.

- Open `index.html` in a browser (or use the hosted link).
- Type a model (for example `F13` or `CE4`) to see the matching box.
- Models not in the list use the AI button (works only in the hosted version).

Box photos are `box1.jpg` to `box40.jpg`. The model lists are typed from the photos and should be checked against physical boxes.
